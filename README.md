# شعله 🔥 Sholeh

**Premium offline habit & fitness tracker**

- 30 languages (فارسی، English، العربية، Español، Français، Deutsch، 中文، 日本語، 한국어، Русский + 20 more)
- PIN lock security (SHA-256)
- Top-page reminder banner + browser notifications
- Confetti celebrations, streak ring, glass design
- Fully offline — data never leaves your device
- Export / Import / Clear data
- Dark & Light themes
- Ready for PWA / Capacitor / GitHub → App

## Run
Open `index.html` or `npx serve .`

## Convert to mobile app
Upload this folder to GitHub → use Capacitor or PWA Builder.
